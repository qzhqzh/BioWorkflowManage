# 扩增子 Panel 管理与执行

## 契约与兼容边界

本次为平台 additive 能力，上游显式选择新的 `amp-panels@2.0.0` 产品契约。原 `lc103-amp@1.2.0` 与固定枚举的 `amp-panels@1.0.0` 保留原行为及不可变快照。不会原地修改已发布版本、旧任务或其他接入方的绑定。

2.0.0 的发布清单是 `examples/nextflow-amp-panels/managed-product-manifest.json`。算法仍为 `01_amp_pipeline.nf`，业务名称为“LC103 扩增子”。通过 `runtime_manifest.panel_input_binding` 显式声明编号、BED 内容、SHA256 输入和固定 Nextflow 参数名及参考索引路径。

## Panel 与文件

一个 Panel 有编号、名称、启用状态；每个版本固定一个 hg19 BED 文件。LC103、MGG1064 的初始文件来自原扩增子源码，不生成或扩展生信区域。用户可新增自己的 Panel，也可上传同一 Panel 的新版本。相同规范化内容重传复用已有版本；文件内容不能覆盖。

当前格式为 UTF-8、制表符分隔的 8 列 BED，最大 1 MiB。去除 BOM、注释和空行，统一换行，其他内容不改写。检查坐标、内部区域包含关系、重复名称、染色体和参考范围。坐标范围检查不证明文件实际源自 hg19，提供者仍需确认参考基因组及实验适用性。

BED 属于小型流程配置，采用已声明的 String 输入传递有界内容，不新增共享宿主机目录、不让上游指定执行路径。大型 FASTQ 和结果继续使用原受管文件/对象机制。本方式不适用于大型参考库或任意文件上传。

## 提交约定

`inputs` 必须包含原 FASTQ 引用及：

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `panel` | String | 安全格式的 Panel 编号 |
| `panel_version` | String | 上游固定版本标识，例如 HS430@v1 |
| `panel_bed` | String | 规范化的 BED8 内容，最多 1 MiB |
| `panel_bed_sha256` | String | BED UTF-8 字节的 64 位小写 SHA256 |

这些是新分析产品的输入端口，Integration API 顶层请求形状不变。其他产品不自动接受这些参数。平台预检及执行前均验证内容、摘要及固定参考索引；失败使用已有 `INPUT_CONSTRAINT_INVALID` 类别。

Worker 将已冻结内容写入该次执行的 `inputs/panel-<sha256>.bed`，同时传入 `--panel` 和 `--amp_target`。文件不可由上游指定路径，已有暂存文件必须匹配摘要，符号链接不允许。Nextflow 读取此固定 BED，不从可变的业务产品配置重新取文件。重试同一平台运行沿用原输入快照。

## OKBOX 接入与升级

OKBOX 在“配置管理 → Panel 管理”管理版本，检测产品绑定明确的 PanelVersion。上传新版本不会自动切换已关联产品。新任务创建时将 BED 内容、编号、版本标识、摘要写入任务输入及冻结请求。停用 Panel 会阻止之后的新任务，已接受任务仍使用其快照。

本次 OKBOX 增量迁移创建 Panel/PanelVersion，登记两份预置 BED，已有扩增子产品默认关联 LC103 v1（已有明确 MGG1064 选择则保留）。先更新 BWM API、Nextflow Worker 并导入发布 2.0.0；更新 OKBOX 镜像并备份、迁移数据库后，执行：

```bash
python manage.py configure_amp_panels
```

此命令先核对公开 BWM 产品契约，再统一产品绑定，在 OKBOX 列表中保留一个“LC103 扩增子”流程。旧重复条目停用而不删除，历史执行记录不改写。命令可重复执行，保留已有用户 Panel 版本选择；失败时事务回滚。首次数据库迁移与 BWM 发布不包含在该命令中。

如需回退界面或服务镜像，先核对仍在执行的任务，保留新表、旧契约和任务快照；不要反向删除迁移或 BED。检测产品的报告模板与热点规则独立管理，不因 Panel 更换自动更新。

## 验证

覆盖上传权限、非法格式与参考范围、上传失败回滚、重复内容、版本不可覆盖、产品绑定、旧任务冻结、固定枚举与原 Nextflow 兼容。真实小数据运行用于确认执行器读取上传 BED；不代表任意新 Panel 已完成生信或报告验收。

本轮为本机热更新，尚未发布新的服务镜像或客户部署标签。
