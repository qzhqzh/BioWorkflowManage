# 给 AI 的文档
把固定版本的上下文交给开发助手，生成可核验的部署与接入代码。

## 读取入口 {#read}

| 入口 | 用途 |
| --- | --- |
| [llms.txt](/llms.txt) | 文档索引与固定版本信息 |
| [完整公开文档](/llms-full.txt) | 安装、部署、使用、接入与测评的纯文本 |
| [接入上下文](/docs/ai-context.md) | 可直接复制给开发助手的接入说明 |
| [OpenAPI](/openapi.json) | 本版 API 结构，文档修订号 1.7.0 |
| [接入指南 Markdown](/docs/integration.md) | 最小闭环及双方责任 |

首页的“复制接入说明”会复制公开 Markdown，不读取你的部署配置或 Token。以下内容用于指导开发，不是授予助手访问生产环境的权限。

## 可复制的任务说明 {#prompt}

```text
请为我的业务后端接入 BioWorkflowManage v1.1.0。

先读：
https://bwm.qzhqzh.com/docs/integration.md
https://bwm.qzhqzh.com/openapi.json

根据项目现有语言、配置和任务队列实现接入。
先确认部署地址、产品代码、契约版本、契约摘要与输入输出要求。
凭据从后端密钥配置读取，不让我在对话中粘贴 Token。

需要验证：
固定产品 → 输入预检 → 幂等提交 → 超时找回 → 状态同步 → 结果校验。
保留外部执行 ID 和请求快照，处理重复请求、乱序状态和结果重复入库。
使用脱敏测试数据。没有真实环境证据时，不声称业务联调或生产验收通过。
```

## 实现约束 {#rules}

- 以 OpenAPI 和具体产品契约为准，不猜测端点、字段、枚举或输入类型。
- 业务用户、样本业务、报告规则和展示留在业务应用，底座仅提供分析服务。
- 固定 `analysis_code + contract_version + contract_digest`，不自动升级产品、不直接访问底座数据库。
- 输入先完成投递；受管路径不是上传接口，不允许请求自选宿主路径、脚本或镜像。
- 相同分析在网络重试时使用原幂等键、原外部执行 ID、原请求内容。
- 后端持久同步状态；区分执行成功、输出完整、文件交付和业务解析。
- 下载只使用可信同源地址，校验大小与 SHA-256，不把 Token 交给浏览器。
- 新能力显式启用，已有契约与历史任务证据不原地修改。

## 验证交付 {#verify}

提交可复现的安装记录、正向与失败路径、幂等测试、超时恢复、结果摘要校验和版本清单。具体任务验收以 [试部署与测评](/docs/evaluation/) 为准。

部署指引、代码已生成、单元测试通过和真实业务验收是不同证据。对缺失的执行条件明确说明，不能用示例数据或页面状态替代真实执行。
